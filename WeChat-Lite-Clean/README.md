# 🚮 WeChat-Lite (Clean Edition)

息屏时自动清理微信多余后台进程，**仅保留主进程与 Push 服务**，减少无用后台占用，温和省电。

> 本项目基于 [Whitelist520/WeChat-Lite](https://t.me/Whitelist520) 原模块逆向分析后**重写的纯净版本**。
>
> 原版代码经过重度多层混淆、含 1.9MB 推广视频、安装时自动打开 Telegram 频道链接。此版本去掉了所有混淆和推广，保留核心功能并以明文呈现。

---

## 功能

- **息屏自动检测**：利用 `dumpsys window policy` 判断屏幕状态
- **微信前台保护**：微信正在前台使用时绝不干预
- **批量温和清理**：
  1. 先对所有目标进程发送 `SIGTERM(-15)`，给微信保存状态的机会
  2. 统一等待 2 秒
  3. 检查哪些进程还活着，补 `SIGKILL(-9)` 强制终止
- **Push 服务保留**：`com.tencent.mm:push` 不受影响，消息照常接收
- **每 2 分钟检查一次**，不频繁轮询
- **自带运行日志**：刷入后可在 `/data/adb/modules/WeChat-Lite-Clean/clean.log` 查看

## 与原版对比

| | 原版 | 纯净版 |
|---|---|---|
| **代码** | 多层 base64 + 字节替换混淆，不可读 | **纯明文**，一眼看懂 |
| **模块大小** | ~2.0 MB（含 1.9MB 推广视频） | **~2.3 KB** |
| **杀进程方式** | `kill -9` 直接强杀 | **先 -15，2 秒后再 -9**（批量处理） |
| **检查间隔** | 60 秒 | **120 秒** |
| **`[[ ]]` 语法** | 使用 `[[ ]]`，BusyBox sh 不兼容 | **改用 `case`**，全环境兼容 |
| **TG 推广** | 安装时自动打开频道链接 | **无** |
| **cron 依赖** | 需要 crond 守护进程 | **不需要**，自身后台循环 |
| **日志** | 无 | **有**，写入 `clean.log` |
| **视频文件** | 1.9MB mp4 推广视频 | **已删除** |

## 刷入方式

### 前提

- 手机已 Root（Magisk / KernelSU / APatch 均可）
- 已安装对应管理器

### 步骤

1. 下载 `WeChat-Lite-Clean.zip`
2. 打开 Magisk Manager / KernelSU → **模块** → **从本地安装**
3. 选中 zip → 等待刷入完成 → **重启**

### 卸载

管理器里直接卸载模块即可，无残留。

---

## 运行日志

刷入重启后，日志文件位于：

```
/data/adb/modules/WeChat-Lite-Clean/clean.log
```

示例输出：

```
2025-08-13 15:30:01  模块启动，开始监控微信后台……
2025-08-13 15:32:01  息屏，发现子进程：12345 12346 12347
2025-08-13 15:32:01    SIGTERM 已发送，等待 2 秒……
2025-08-13 15:32:03    所有进程已正常退出 ✓
```

日志超过 500KB 自动清空轮转，不占空间。
